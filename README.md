SRM RAILWAYS - Online Railway Ticket Booking System

Live Website: https://swayamsinghrajput007-hash.github.io/SRM_Railways/

About the Project:

This is a web-based project I developed to make railway ticket booking easier and more accessible for passengers. The system provides a simple and interactive platform where users can search for trains, check availability, book tickets, and manage their bookings without visiting the railway station.

I created this project to apply my web development and C++ programming skills and to understand how a real-world booking system works from both frontend and backend perspectives.

Features:

Search trains by From, To, and Train Number
View live train availability and routes
Select Journey Date, Class (SL, 3A, 2A, 1A) and Quota (General, Tatkal, Ladies,Senior Citizen)
Tatkal booking with IRCTC timing validation (Popup at 8 AM / 10 AM / 11 AM)
Passenger details and seat allocation
Automatic PNR generation for every booking
Ticket Preview with full journey details
Download ticket as PDF with QR Code
Working QR Code scanner for ticket validation
PNR Status check
Save booking history using file handling / local storage
Technologies Used:

Frontend: HTML, CSS, JavaScript

Backend Logic: C++

Libraries Used: jsPDF (for PDF ticket), html5-qrcode (for QR scanner)

Object-Oriented Programming (OOP)

File Handling

OOP Concepts Used:

Encapsulation: Used classes like Train, Passenger, Ticket, BookingSystem to keep related data and functions together.
Abstraction: Created an abstract class to define common booking operations, hiding complex logic from the user.
Inheritance: Different ticket types and user roles inherit common properties from base classes.
Polymorphism: Used virtual functions for different implementations of ticket booking, cancellation, and fare calculation.
